개인정보처리방침

kiwiki는 운영자가 본인의 Google 계정과 개인용 AI 자동화 도구를 연결하기 위해 사용하는 OAuth 애플리케이션입니다. 이 문서는 Google 사용자 데이터에 대한 접근, 사용, 보관 및 권한 철회 방법을 설명합니다.

시행일: 2026년 10월 24일 · 버전 1.0
운영 주체접근 가능한 정보이용 목적제3자 처리와 제공저장 및 보관권한 철회와 삭제웹사이트 방문 정보문의 및 변경

1. 운영 주체와 사용 대상

kiwiki는 개인 개발자·운영자가 본인의 자동화 환경에서 사용하는 비공개 운영용 Google OAuth 연동 앱입니다. 누구나 가입하는 공개 서비스가 아니며, Google에서 제공하거나 보증하는 공식 서비스가 아닙니다.

운영자 GitHub 계정: github.com/kimisjun. 연락은 Google OAuth 동의 화면에 표시된 사용자 지원 이메일을 이용할 수 있습니다.

2. 접근 가능한 Google 사용자 데이터

각 Google 계정에서 직접 허용한 OAuth 권한에 한하여 다음 유형의 데이터에 접근할 수 있습니다.

  • Gmail: 메일 제목, 본문, 발신자·수신자, 첨부파일 및 메일 상태. 승인된 기능에 따라 메일 조회·발송·수정이 가능할 수 있습니다.
  • Google Drive 및 문서 도구: 파일 이름, 내용, 메타데이터, 문서·스프레드시트·프레젠테이션의 내용을 읽거나 승인된 범위에서 생성·수정할 수 있습니다.
  • Google Calendar: 일정 제목, 시간, 설명 및 참석자 정보. 승인된 범위에서 일정을 조회·변경할 수 있습니다.
  • Google Contacts: 사용자가 접근을 허용한 연락처와 관련 정보.

모든 항목에 항상 접근하는 것은 아닙니다. 실제 범위는 Google 권한 동의 화면, 연결된 계정 및 실행 환경별 설정에 따라 달라집니다.

3. 정보 이용 목적

데이터는 운영자가 요청하거나 미리 구성한 개인 업무 자동화, 일정 확인과 정리, 문서·프레젠테이션 보조, 메일 분류 및 작성 등의 기능 제공에 필요한 범위에서 사용합니다.

개인용 Google API 연결을 광고 프로파일링, 광고 타겟팅, 사용자 데이터 판매 목적으로 사용하지 않습니다. 운영자는 Google API Services User Data Policy의 제한적 사용(Limited Use) 원칙을 준수하도록 설정과 데이터 흐름을 관리합니다.

4. 제3자 처리와 제공

kiwiki는 Google API를 통해 사용자가 승인한 데이터에 접근합니다. 자동화 기능에 AI 모델을 사용하는 경우, 선택된 작업을 처리하기 위해 관련 데이터 일부가 운영자가 설정한 AI 모델 제공업체로 전송될 수 있습니다. 이는 사용 중인 AI 도구와 해당 설정에 따라 다르며, 모든 Google 데이터가 자동으로 전송되는 것은 아닙니다.

관련 플랫폼 또는 API 공급업체의 별도 개인정보처리 조건이 적용될 수 있습니다. Google 사용자 데이터를 광고 타겟팅 목적으로 판매하거나 제공하지 않습니다.

5. 저장 및 보관

OAuth 접근·갱신 토큰은 운영자가 관리하는 인증 실행 환경에 보관될 수 있습니다. Google API에서 받은 데이터와 작업 결과는 실행 환경의 문서, 임시 파일, 캐시, 로그 또는 백업에 필요한 기간 동안 남을 수 있습니다. 실제 보관 위치와 기간은 각 자동화 도구의 구성 및 데이터 유형에 따라 다릅니다.

인증 토큰, 개인정보 또는 Google 사용자 데이터는 이 공개 소개 웹사이트의 소스 코드에 포함하지 않습니다.

6. 권한 철회와 데이터 삭제

연결된 Google 계정의 접근 권한은 Google 계정의 타사 앱 연결 관리에서 kiwiki 앱의 권한을 철회하여 중지할 수 있습니다.

권한 철회만으로 이전에 생성된 로컬 문서·캐시·로그·백업이 모두 삭제되는 것은 아닐 수 있습니다. 이러한 사본과 인증 토큰의 삭제가 필요하면 운영자가 해당 실행 환경에서 직접 삭제·확인해야 합니다.

7. 이 소개 웹사이트의 방문 정보

이 웹사이트는 정적 안내 페이지이며 별도의 로그인, 사용자 입력 양식, 분석 도구 또는 광고 추적 스크립트를 포함하지 않습니다. GitHub Pages를 통해 게시되는 경우 호스팅 제공업체 GitHub가 서비스 제공 및 보안 목적으로 접속 정보를 처리할 수 있습니다. 자세한 사항은 GitHub 개인정보처리방침을 확인해 주세요.

8. 문의 및 정책 변경

이 앱의 운영·Google 권한 사용 관련 문의는 Google OAuth 동의 화면에 기재된 사용자 지원 이메일로 보낼 수 있습니다. 공개 GitHub 저장소나 이슈에 비밀번호, 이메일 본문, 인증 코드, 토큰 또는 그 밖의 민감정보를 남기지 마세요.

기능과 실제 데이터 처리 방식이 변경되면 본 문서를 갱신하고 시행일을 표시합니다.

본 정책은 개인 운영용 Google API 연결의 공개 고지입니다. 개별 자동화 환경의 설정·외부 모델 사용 현황과 일치하는지 운영자가 게시 전에 검토해야 합니다.
