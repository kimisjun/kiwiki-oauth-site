01 — PURPOSE

무엇을 연결하나요?

kiwiki는 개인 소유의 자동화·보조 도구가 승인받은 Google API 기능을 활용하도록 돕는 인증 연결용 앱입니다.

01

Google Drive · Docs · Sheets · Slides

승인된 파일을 조회하고 정리하거나, 문서·스프레드시트·프레젠테이션 작업을 돕습니다.

02

Gmail · Calendar · Contacts

사용자가 구성한 업무에 따라 메일, 일정, 연락처를 조회·관리하거나 사용자 지시에 따라 관련 작업을 수행합니다.

03

AI 자동화 보조

운영자가 관리하는 AI 도구가 필요한 맥락을 이해하고 반복 작업을 보조하도록 서비스 간 연결을 제공합니다.

실제로 허용되는 데이터와 작업은 각 Google 인증 동의 화면에 표시되는 권한 범위와 도구 구성에 따라 달라집니다.

02 — CONTROL

접근 권한은
사용자가 관리합니다.

Google 계정 데이터는 사용자가 Google의 공식 동의 화면에서 권한을 허용한 경우에만 접근할 수 있습니다.

운영자는 설정된 작업에 필요한 범위에서 데이터를 활용합니다. 연결 권한은 Google 계정의 타사 앱 연결 관리 페이지에서 언제든 철회할 수 있습니다.
